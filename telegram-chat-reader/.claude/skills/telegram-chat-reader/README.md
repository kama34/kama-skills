# Первый запуск Telegram Chat Reader на Mac

Можно начать без ключей и приложения разработчика. Агент устанавливает скилл и зависимости, помогает заполнить форму Telegram и проверяет результат. Владелец сам входит в личный кабинет и вводит секреты в локальном Terminal. Достаточно сказать агенту: «Установи telegram-chat-reader и помоги мне подключить мою телегу».

## Установить скилл

1. Проверь ОС. Эта версия работает на macOS и использует системную связку ключей Keychain. Если Mac отсутствует, скажи об этом до установки.
2. Возьми каталог `telegram-chat-reader/.claude/skills/telegram-chat-reader/` из этой версии репозитория. Скопируй **содержимое каталога** в персональную папку навыка. Для Codex это `${CODEX_HOME:-$HOME/.codex}/skills/telegram-chat-reader/`, для Claude Code — `~/.claude/skills/telegram-chat-reader/`. Проверь, что на одном уровне лежат `SKILL.md`, `README.md` и `scripts/`. Если установленная копия отличается, сохрани локальные изменения перед обновлением.
3. Проверь `python3 --version` и `brew --version`. Нужен Python 3.10 или новее. Если Homebrew отсутствует, помоги владельцу поставить его с [официального сайта](https://brew.sh/) и выполнить указанные установщиком шаги для PATH. Недостающий Python установи через `brew install python`. Для TDLib установи `brew install --HEAD tdlib`: у стабильной 1.8.0 более старая схема команд. Если подходящая версия уже загружается, используй её. Проверка из корня установленного скилла: `PYTHONPATH=scripts python3 -c 'from reader import TDLib; print(TDLib().version)'`. Для нестандартной установки задай `TDJSON_LIBRARY` с абсолютным путём к `libtdjson.dylib` и в Terminal владельца. [Формула TDLib](https://formulae.brew.sh/formula/tdlib)
4. Из этого каталога запусти `python3 scripts/reader.py status`. Если ответ содержит `"authorized": true`, переходи к проверке выбранного чата. На чистом Mac ожидается `login_required`. Голосовые, OCR и модели для расшифровки можно настроить позже по [инструкции скилла](SKILL.md).

## Получить ключи своего приложения Telegram

Показывай владельцу один следующий шаг и попроси сообщить только о его завершении. Все значения остаются у владельца.

1. Нужен обычный аккаунт Telegram с доступом к сообщениям для входа. Если аккаунта пока нет, владелец сначала регистрируется в [официальном клиенте Telegram](https://telegram.org/apps).
2. Предложи открыть [API development tools](https://my.telegram.org/apps) в личном браузере. Владелец вводит номер с кодом страны и подтверждает вход способом, который укажет Telegram.
3. Если кабинет показывает форму **Create new application**, помоги заполнить её. Для **App title** подойдёт `My Local Chat Reader`, для **Short name** — своё короткое имя латиницей. Выбери платформу **Desktop** и укажи в описании, что это локальный клиент для чтения выбранных чатов. Затем владелец нажимает **Create application**. Если кабинет уже показывает **App api_id** и **App api_hash**, используй это приложение. [Инструкция Telegram](https://core.telegram.org/api/obtaining_api_id)
4. Попроси оставить страницу открытой для ввода в Terminal. Агенту достаточно знать, что оба значения появились. Номер, ключи, коды входа, пароль и скриншот страницы в чат отправлять не нужно.

## Войти один раз в Terminal

Дай владельцу готовую команду с абсолютным путём к установленному скрипту и тому Python, который проверен выше. Например, при обычной установке Codex:

```sh
python3 "${CODEX_HOME:-$HOME/.codex}/skills/telegram-chat-reader/scripts/reader.py" login
```

Команду запускает владелец в своём интерактивном Terminal. При новой установке скрипт сам находит пользовательскую связку ключей. Последовательно появятся запросы для **api_id** и **api_hash**. Владелец вводит каждое значение в соответствующем запросе macOS `password data for new item` и повторяет для подтверждения. Символы на экране не отображаются. При повторном запуске уже сохранённые элементы используются снова.

Затем скрипт запросит телефон в международном формате и код входа Telegram. Если аккаунт защищён двухэтапной проверкой или Telegram запросит email, Terminal покажет следующий запрос. Дождись результата `"authorized": true`. Связка ключей хранит ключи, а локальный каталог `~/Library/Application Support/2030ai/telegram-chat-reader/` — привязку аккаунта и сессию. В `credentials.json` остаются только ссылки на элементы Keychain.

## Проверить подключение

Снова запусти `python3 scripts/reader.py status` из установленного каталога. Ответ `"authorized": true` показывает, что скрипт узнаёт аккаунт. Для проверки чтения попроси владельца выбрать один чат и, если требуется, точное название разрешённой папки. Подставь их в команду:

```sh
python3 scripts/reader.py history --chat 'ССЫЛКА НА СООБЩЕНИЕ' --limit 1
```

Если владелец ограничил доступ папкой, добавь `--folder 'НАЗВАНИЕ ПАПКИ'` уже в первую проверку. Ссылка выбирает чат. По умолчанию команда ищет сообщения с текстом за последнюю неделю. Если их нет, проверь согласованный период через `--since` или попроси ссылку на активный чат. Для подтверждения достаточно сообщить, удалось ли прочитать сообщение. Полный вывод с перепиской содержит личные данные.

## Если установка остановилась

- **Команда login требует интерактивный терминал.** Покажи команду для Terminal владельца. После входа агент может сам выполнить проверку status.
- **Скрипт не видит TDLib или сообщает об устаревшей схеме.** Проверь, какую библиотеку загружает Python, и наличие сборки HEAD. Для её сборки может понадобиться установить Command Line Tools через `xcode-select --install`.
- **Keychain заблокирована или ключи неверны.** Открой «Связка ключей» (Keychain Access), разблокируй пользовательскую связку и проверь элементы `telegram-chat-reader.api_id` и `telegram-chat-reader.api_hash`. Исправь ошибочное значение там и повтори login. При ранее настроенной отдельной связке используй ссылки из её конфигурации.
- **Telegram отклонил код.** Владелец повторяет login и вводит актуальный код из канала, указанного Telegram. При ограничении частоты попыток дождись срока, указанного сервисом.
- **Вход подтверждён, но чат не найден.** Проверь аккаунт, точную ссылку или название и членство в выбранной папке. Секретные и защищённые чаты скилл пропускает.
