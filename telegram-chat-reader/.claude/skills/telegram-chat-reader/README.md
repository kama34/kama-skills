# Telegram Chat Reader — первый запуск

Скилл читает один выбранный чат Telegram на macOS, Windows и Linux. Можно начать с обычного аккаунта без приложения разработчика и API-ключей. Передайте агенту ссылку на эту инструкцию и попросите: **«Установи telegram-chat-reader для моей системы и проведи меня до первого чтения чата»**.

Агент выполняет установку и проверки. Владелец входит в личный кабинет Telegram в своём браузере, а затем вводит ключи и код входа в терминале на своём компьютере. Помогай по одному шагу. Для продолжения достаточно ответа «готово».

## Установка для агента

1. Определи систему и архитектуру машины, на которой будет работать агент. На Windows используй нативный Python и PowerShell. На Linux нужен пользовательский сеанс D-Bus с разблокируемым Secret Service, например GNOME Keyring. Установка на компьютере пользователя сохраняет сессию между запусками агента.
2. Скопируй **содержимое** каталога `telegram-chat-reader/.claude/skills/telegram-chat-reader/` из той версии репозитория, ссылку на которую дал владелец. Для Codex целевой каталог — `skills/telegram-chat-reader` внутри `CODEX_HOME` (по умолчанию `~/.codex`). Для Claude Code — `~/.claude/skills/telegram-chat-reader/`. Если там уже есть локальная редакция, проверь отличия перед обновлением. Перейди в установленный каталог. На одном уровне должны лежать `SKILL.md`, `README.md`, `requirements.txt`, `scripts/` и `references/`.
3. Проверь Python. Для базовой установки подойдёт 64-битный Python 3.12. Код поддерживает Python 3.10 и новее, доступность готовых сборок TDLib зависит от версии Python и архитектуры. Если Python отсутствует, на Windows установи официальный Python с поддержкой `py`, на macOS — Python с python.org или через Homebrew, на Linux — Python и модуль venv из пакетов дистрибутива. Для Debian/Ubuntu обычно нужны `python3` и `python3-venv`. [Python для Windows и macOS](https://www.python.org/downloads/)
4. Создай окружение командой для своей ОС. Выполняй следующие команды из **корня установленного скилла**. Активация окружения не требуется. На Linux с GNOME проверь наличие Secret Service в сеансе владельца. В Debian/Ubuntu провайдер устанавливается пакетом `gnome-keyring`. Для Linux без графического входа сначала настрой пользовательскую D-Bus-сессию и способ разблокировать связку ключей. [Документация keyring](https://keyring.readthedocs.io/en/latest/#using-keyring-on-headless-linux-systems)

**macOS и Linux** (Terminal)

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip install --only-binary=:all: tdjson==1.8.71
.venv/bin/python -c "import sys; sys.path.insert(0, 'scripts'); from reader import TDLib; print(TDLib().version)"
.venv/bin/python scripts/reader.py status
```

**Windows** (PowerShell)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install --only-binary=:all: tdjson==1.8.71
.\.venv\Scripts\python.exe -c "import sys; sys.path.insert(0, 'scripts'); from reader import TDLib; print(TDLib().version)"
.\.venv\Scripts\python.exe scripts\reader.py status
```

Если готового пакета для этой архитектуры нет или версия TDLib не выводится, используй [установку системной библиотеки для этой ОС](references/tdlib.md), затем повтори проверку версии. Успешный `status` с `"authorized": true` означает, что можно сразу [проверить выбранный чат](#проверить-выбранный-чат). На чистом компьютере ожидается `login_required`.

## Создать своё приложение Telegram

1. У владельца должен быть доступ к своему обычному аккаунту. Если его ещё нет, помоги зарегистрироваться через [официальный клиент Telegram](https://telegram.org/apps).
2. Предложи открыть [API development tools](https://my.telegram.org/apps) в личном браузере. Владелец вводит номер с кодом страны и подтверждает вход способом, который укажет Telegram.
3. Если появилась форма **Create new application**, помоги заполнить поля. Для **App title** можно взять `My Local Chat Reader`, для **Short name** — своё короткое имя латиницей. Укажи платформу **Desktop** и краткое описание локального клиента. Затем владелец нажимает **Create application**. Если кабинет уже показывает **App api_id** и **App api_hash**, используй их. [Инструкция Telegram](https://core.telegram.org/api/obtaining_api_id)
4. Попроси оставить страницу открытой для ввода в терминале. Номер телефона, ключи, код входа, пароль и скриншот страницы остаются у владельца.

## Авторизоваться

Дай владельцу **одну готовую команду** с абсолютными путями к Python окружения и скрипту. В PowerShell перед заключённым в кавычки путём к Python поставь оператор `&`. Если терминал уже открыт в каталоге скилла, команды короче:

| Где запустить | Команда |
| --- | --- |
| macOS или Linux, терминал владельца | `.venv/bin/python scripts/reader.py login` |
| Windows, PowerShell владельца | `.\.venv\Scripts\python.exe scripts\reader.py login` |

Владелец по очереди вводит **api_id** и **api_hash**. Ввод скрыт. На macOS системный запрос попросит повторить каждое новое значение для подтверждения. Затем скрипт запросит телефон в международном формате, код от Telegram и, если потребуется, email или пароль двухэтапной проверки. После прерывания достаточно снова запустить `login` под тем же пользователем.

| ОС | Где хранятся ключи | Где хранится сессия TDLib |
| --- | --- | --- |
| macOS | Пользовательская связка Keychain | `~/Library/Application Support/2030ai/telegram-chat-reader/` |
| Windows | Диспетчер учётных данных текущего пользователя | `%LOCALAPPDATA%\telegram-chat-reader\` |
| Linux | Secret Service текущего пользователя | `$XDG_DATA_HOME/telegram-chat-reader/` или `~/.local/share/telegram-chat-reader/` |

Сессия привязана к локальному аккаунту ОС и Telegram. В JSON сохраняется описание хранилища, а ключи остаются в нём. Каталог сессии содержит данные входа. Для передачи скилла другому человеку достаточно ссылки на репозиторий.

## Проверить выбранный чат

Повтори `status` тем же интерпретатором и проверь `"authorized": true`. Спроси, какой **один** чат владелец разрешает прочитать, и нужна ли точная папка. Относительно каталога скилла:

```sh
.venv/bin/python scripts/reader.py history --chat 'ССЫЛКА НА СООБЩЕНИЕ' --limit 1
```

```powershell
.\.venv\Scripts\python.exe scripts\reader.py history --chat 'ССЫЛКА НА СООБЩЕНИЕ' --limit 1
```

Если доступ ограничен папкой, добавь `--folder 'НАЗВАНИЕ ПАПКИ'` уже к первой проверке. Ссылка выбирает чат. По умолчанию ридер ищет текст за последнюю неделю. Если сообщений нет, уточни период для `--since` или попроси ссылку на активный чат. Для отчёта достаточно подтвердить результат без вывода личной переписки.

## Если настройка остановилась

- **Не найден модуль или библиотека.** Проверь, что агент и владелец запускают Python из одного окружения. Для TDLib смотри [инструкцию для трёх платформ](references/tdlib.md).
- **Хранилище ключей недоступно.** На macOS разблокируй Keychain, на Windows запусти PowerShell от обычного пользователя в его сеансе, на Linux проверь активную D-Bus-сессию и разблокируй связку Secret Service. Значения имеют имена `telegram-chat-reader.api_id` и `telegram-chat-reader.api_hash`. При прежней конфигурации macOS используются указанные в ней элементы.
- **Требуется интерактивный терминал.** Передай владельцу команду `login` для его локального терминала. Проверку `status` агент выполняет после входа.
- **Telegram отклонил код или ограничил число попыток.** Используй актуальный код из указанного Telegram канала. Если сервис назначил время ожидания, дождись его.
- **Чат не найден.** Проверь аккаунт, точную ссылку и принадлежность чата разрешённой папке. Защищённые и секретные чаты ридер пропускает.

Для чтения обычных сообщений достаточно шагов выше. Распознавание фото, извлечение текста PDF и локальная расшифровка голосовых подключаются по [инструкции для вложений](references/media.md). Команды и ограничения по чатам описаны в [SKILL.md](SKILL.md).
