# Telegram Chat Reader

Скилл для macOS читает историю одного выбранного чата через личный аккаунт Telegram. Можно указать ссылку на сообщение, точное название чата или папку, которой ограничено чтение.

Передайте агенту ссылку на эту страницу и попросите: «Установи мне telegram-chat-reader. Начни с проверки моего Mac и проведи меня до первого чтения чата. У меня пока нет ключей Telegram».

Агенту и владельцу нужна [инструкция по установке и первому входу](.claude/skills/telegram-chat-reader/README.md). Рядом с ней находятся [сам скилл](.claude/skills/telegram-chat-reader/SKILL.md) и его скрипты. Комплект подходит для установки в Codex и Claude Code.
